## JL

### 稳定特征

- 入池率超过 90%，翻前范围非常宽。
- 喜欢买牌，顶对与听牌粘性高；call 范围宽不代表 raise/shove 范围同样宽。
- `对子 + 听牌`有时会激进，但不是默认高频 shove。
- 水上时相对理性；连续输钱或情绪上头时，大尺度下注、半诈唬和 shove 明显增加。
- 深筹码本身不再作为攻击性增加的触发条件。
- 面对 Hero 时天然不信任；Hero 大尺度下注会提高其 bluff-catch 意愿。

### 动作线路修正

- 正常状态下，JL 突然大柱或 raise 大概率有成牌，诈唬只占较低比例。
- Hand 02 的 `37s` 成顺后 check-shove 支持“突然大动作价值权重高”。
- Hand 03 的 `68 pair + draw` shove 证明半诈唬必须保留非零概率，但单一样本不足以把它提高为常态。
- Hand 01 的 QQ 接 Hero 约 300BB shove，只证明 premium pair 对 Hero 可以打光，不能外推到 JJ/AQ。
- Hand 04/05 支持 JL 面对 Hero 大尺度时会宽跟，但也会在后续街停止支付。

### 当前校准方向

| 特征                      | 方向         | 置信度           |
| ------------------------- | ------------ | ---------------- |
| VPIP                      | 极高（>90%） | 高               |
| 普通 call 范围            | 很宽         | 高               |
| 突然大柱/raise 的价值权重 | 高           | 中高             |
| 正常状态大尺度诈唬        | 低           | 中               |
| pair + draw 激进频率      | 中等、偶发   | 中               |
| 连输/tilt 后攻击性        | 显著升高     | 高               |
| 水上状态理性程度          | 高于其常态   | 用户先验，待样本 |

> 待确认：用户提到的“翻前大约 60 open、15% 跟注大盲尺寸”的精确定义尚未写入数值参数。

## JJ

### 稳定特征

- 整体主动进攻较少，主要通过 call 继续。
- 中等牌力具有明显粘性。
- 面对 Hero 天然不信任；Hero 下大柱时，持有顶对通常会跟。
- 有大牌时约一半主动进攻、一半慢打蹲人，因此被动线路不能自动判弱。
- “粘”主要扩大 call 范围，不能扩展为宽 raise/shove。

### 牌例证据

- Hand 04 中在 `6-7-7` 面对 Hero 大 raise 继续，支持宽 call 与中等牌力粘性。
- Hand 05 中面对 Hero flop 2x pot 仍然继续，支持其对 Hero 的高 bluff-catch 倾向。
- 当前样本没有支持 JJ 高频主动诈唬或宽 shove。

### 当前校准方向

| 特征                   | 方向     | 置信度               |
| ---------------------- | -------- | -------------------- |
| 普通 call 范围         | 宽       | 高                   |
| 中等牌力粘性           | 高       | 高                   |
| 主动进攻频率           | 低       | 中高                 |
| 大牌主动进攻/慢打      | 约 50/50 | 用户先验，待更多样本 |
| 对 Hero 大柱的顶对跟注 | 高       | 高                   |
| 主动诈唬/shove         | 低       | 中                   |

## 23

- 相对理性，有一定理论基础。
- 会综合位置、赔率、有效筹码、牌面和双方范围。
- bluff/value 比 JL、JJ 更有结构，但不是 solver。
- 是当前唯一不对 Hero 保持天然不信任的玩家；面对 Hero 大柱仍按范围和证据更新。
- 本批真实牌例没有提供直接校准证据，画像暂不调整。

## HG

- 中等偏稳，有基本判断能力，不过度 bluff，也不过度粘。
- 对 Hero 天然不信任；面对 Hero 大柱时，持有顶对通常会继续。
- 本批真实牌例没有 HG 的有效摊牌证据，除用户直接描述外不增加推断。

## 胖子

- 相对理性、会算赔率，整体比 23 稍稳、风险偏好稍低。
- 对 Hero 是明确例外：天然不信任 Hero，面对 Hero 大柱时顶对通常会跟。
- 本批真实牌例没有胖子的有效直接证据，不调整其普通对手下的稳健基线。

## 关系型画像

- 除 23 外，JL、JJ、HG、胖子均对 Hero 天然不信任，尤其不相信 Hero 的大尺度下注。
- 其他所有玩家对 JL、JJ 也不太信任；这种不信任主要影响普通线路的继续范围。
- JL 突然大柱/raise 是例外信号：即使大家平时不信任 JL，此时也应明显提高其成牌权重。
- 关系型画像必须按 `observer -> subject` 独立保存，不能把它合并进玩家的一份全局性格。

## Hero 校准摘要

- 深筹码时容易把“继续”直接升级为打光，存在忽略 call 选项的问题。
- 已形成正确 fold read 后，偶尔仍会用随机数或情绪替代执行。
- 多人池连续出现强行动时，范围收紧速度不足。
- 尺度与下注目的不稳定：部分中等强度牌为 protection 做得过大，部分坚果牌又漏取价值。
- 对弃牌后恰好击中 board 容易产生结果导向的遗憾。

## 后续校准流程

1. 保存原始牌例、已知事实、不确定字段和当时使用的画像版本。
2. 把每个结论记录为独立证据，包含 trait、confidence、sampleCount 和 sourceHands。
3. 生成小幅画像 patch，不自动改变 active profile。
4. 用户确认后创建新的 `ProfileVersion`；历史牌局继续绑定旧版本。
5. 用来源牌例和后续真实牌例做回归测试，必要时回退画像版本。
