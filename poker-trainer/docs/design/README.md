# Poker Table visual direction

`poker-table-concept-v1.png` 与 `poker-table-mobile-concept-v1.png` 是 Poker Table 页面桌面端、手机端的视觉规范草案。

- 方向：训练工具，而非赌场游戏。
- 背景：深炭黑；牌桌：墨绿；重点动作：暖金；危险动作：克制的红色。
- 容器：开放式牌桌画布、右侧行动轨、底部决策工作区，避免层层卡片。
- 组件边界：App shell、Poker table、Seat、Action timeline、Thought form、Action controls。
- 所有真实 UI 文本、表单和控制保持代码原生；概念图不会直接作为界面背景。
- 手机端：牌桌优先，决策区纵向排列，行动记录使用抽屉，操作区保持在内容底部且适配安全区。
- 断点：`980px` 以下进入窄屏布局，`700px` 以下采用手机端密度与控件尺寸。
